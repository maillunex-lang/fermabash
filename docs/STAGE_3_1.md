# Stage 3.1: Bashkortostan region navigation prototype

Android-first navigation opens from the farm's **Карта** action. It drills down from the republic into a small sample of districts and settlements, then returns to the unchanged existing farm. The prototype currently lists **Уфимский район → Михайловка** and **Стерлитамакский район → Наумовка**. The names are illustrative navigation entries, **not** an exhaustive, officially reconciled OKTMO register or geographical geometry. No district outlines, terrain streaming, ownership, real coordinates, new farm instances or multiplayer are implemented yet. Those require verified administrative data and further stages.

The region screen is informational, makes no save changes and has large Android buttons. The existing farm controls, construction and saves are preserved. Tests cover catalog lookup, UI drilldown, back to farm and unchanged save snapshot. Do not claim the full Bashkortostan map exists.
