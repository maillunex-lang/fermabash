# Visual grade

Presentation only. No economy, pathing or save changes.

Premium pass (stage 5+ visuals):

- Wheat: multi-frequency wind sway, height-based bend, per-stalk variation, fake SSS, specular + strong golden rim/emission on ripe tips.
- Ground: FBM noise grain, wetness specular, richer soil/grass palettes.
- Water: multi-wave normals, sun specular highlights, improved fresnel.
- Sky: better gradient, sun disk + glow, soft hash clouds.
- Post: stronger UnrealBloom, warm contrast color grade, tighter vignette.
- Atmosphere: warmer filmic tonemap, denser pollen + dust particles, richer fog.
- Density: ~2x wheat blades in both Godot MultiMesh and Three.js InstancedMesh.

Android builds stay on gl_compatibility. Shadows stay off so the existing mobile budget is unchanged.
