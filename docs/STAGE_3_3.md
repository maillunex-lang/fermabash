# Stage 3.3: Mobile-friendly city selection

Eight-city beta catalog remains unchanged (hard cap 10). The schematic city map now has a scrollable, labeled city list alongside the geographic pins. Both selection methods synchronize the selected city and make the active item visible in the UI. Touch targets are 56px high or larger. The panel adapts to the viewport and retains the district and back-to-farm controls.

No new cities, official geographic boundaries, game-world teleportation, land ownership, server mechanics or changes to existing saves. This is a navigation/accessibility improvement, not an authoritative cartographic release. Run the full Android test suite and graphical launch before merging.
