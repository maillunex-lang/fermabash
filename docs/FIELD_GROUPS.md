# Поля из нескольких клеток: назначение заданий

- В разделе «Земля и дороги» нажмите «Новое поле 80 ₽/клетка». Все клетки, добавленные в этом режиме, образуют одно поле. Чтобы создать другое поле, нажмите «Новое поле» ещё раз. Даже соприкасающиеся поля останутся независимыми.
- Переключитесь в раздел «Поля», чтобы завершить размещение клеток. Нажмите «Подготовить», «Посев» или «Уборка», затем нажмите **любую клетку** нужного поля. Всё поле подсвечивается и получает одно задание. На исходном стартовом поле тоже можно нажать после выбора действия.
- Каждое новое поле имеет отдельные стадии обработки и роста. Подготовка стоит 25 ₽/клетка, посев 40 ₽/клетка, урожай 3 тонны/клетка. Склад должен вмещать весь урожай поля.
- Если техника уже занята, задания на другие поля ставятся в очередь и выполняются последовательно, не параллельно. Назначение сохраняется. Скорость поездки зависит от дорог.
- Старые сохранения совместимы: каждая ранее купленная клетка остаётся отдельным полем, чтобы не объединять чужие состояния посевов неожиданно. Новые поля объединяются только по явному режиму создания.
- Это локальная Android-альфа. Между игроками пока нет общей земли и серверных заданий. Для реального управления на телефоне требуется дополнительная проверка касаний и интерфейса.
